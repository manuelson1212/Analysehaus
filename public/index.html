The method

Three rules every impulse must obey.

If one is broken, the count is wrong. Hover a rule to see it in the chart above.

  1. Wave 2

    never retraces more than 100% of wave 1.

  2. Wave 3

    is never the shortest of the three impulse waves 1, 3 and 5.

  3. Wave 4

    never enters the price territory of wave 1.

How an analysis is made

From chart to published call, in four steps.

  1. Count

    Label the impulse and correction waves on the chart.

  2. Scenarios

    Define the primary path and the alternate.

  3. Invalidation

    Set the level at which the count no longer holds.

  4. Publish

    Chart, count and levels go online together.
